Reference / Guide

GitHub Auto-Sync & Cache Specification

1. GitHub自動検出の仕組み

起動時およびヘッダーの SYNC 実行時に、GitHub REST API（認証不要・無料）へアクセスし、MSY-hub-TEN/my-apps（main ブランチ）のルート直下にある .html ファイルを自動取得します。index.html 自身は自動的に除外されます。

2. APIレート制限とオフラインキャッシュ

認証なしのGitHub APIには「同一IPあたり1時間60回」の呼び出し制限があります。オフライン環境や制限到達時はエラーで画面を止めず、localStorage に保存された直近のキャッシュ一覧を自動表示し、ステータスを OFFLINE / CACHED または RATE LIMIT / CACHED に切り替えます。

3. ブラウザ上での表示カスタマイズとマージ

自動検出されたカード（REPO バッジ付き）は、編集アイコンから表示名・メモ・タグ・アイコン・ピン留め・非表示を個別に設定できます。設定はファイル名をキーに localStorage へ永続保存されるため、GitHubへ新しいHTMLを追加しても既存設定は消えません。

4. ローカル手動追加との共存

「新規追加」や画面への .html ドロップで登録したアプリは LOCAL としてIndexedDBに保存され、GitHub自動検出アプリと同一の検索・タグ・並び替え・プレイヤー上で共存します。
