Studio Workflow

3つの工房を連携した制作フロー

本アプリはすべての処理をブラウザ標準のCanvas APIとローカル計算のみで実行し、画像やテキストを外部サーバーへ一切送信しません。

01. Palette

写真やプリセットから5〜8色の代表色を抽出・決定し、背景色と文字色のコントラスト比を検証します。

02. Pattern

「Patternへ反映」または「パレット連動」で配色を引き継ぎ、端が綺麗に繋がるシームレス背景を生成します。

03. Typo & Logo

多重縁取り・ネオン・変形を加えたロゴを作成し、透過PNG/SVG単体またはパターンと合成した壁紙・バナーとして書き出します。

Color & WCAG Contrast Reference

色彩抽出アルゴリズム

画像を縮小サンプリングし、K-Means++クラスタリングにより代表カラーを自動抽出します。スウォッチのHEXまたはRGBをタップするとクリップボードへ即座にコピーされ、BG / TEXTボタンでコントラスト検証へ割り当てられます。

WCAG 2.1 コントラスト比と判定基準
AAA (7.0 : 1 以上) — 極めて高い視認性。長文本文や高精度なUIに推奨。
AA Normal (4.5 : 1 以上) — 標準的な本文テキストの推奨基準。
AA Large (3.0 : 1 以上) — 見出し・太字・大型UI部品向けの最低基準。
FAIL (3.0 : 1 未満) — 文字の判読が困難。背景と文字の明度差を広げてください。

Seamless Pattern Specifications

シームレス描画と書き出し

ギンガムチェック、ストライプ、水玉、方眼グリッド、レトロタイル、紙のノイズ質感はすべてCanvasの数式計算で生成されます。角度スナップ（0° / 45° / 90°）を利用すると、単体タイルPNGをCSSの background-repeat やデザインツールのパターン塗りつぶしに使用した際、継ぎ目なく連続します。

背景透過と質感オーバーレイ

「背景透過」をONにすると、模様の線やドットだけを残して透過PNGとして書き出せます。任意の背景色の上に重ねるオーバーレイ素材として活用できます。

Typography & Export Formats

カーニング・多重縁取り・変形

文字間隔（カーニング）は1文字単位の配置座標で制御され、アーチ変形や波打ち変形時にも自然な間隔を維持します。多重縁取りは「第2縁取り（外側）→ 第1縁取り（内側）→ 塗り」のレイヤー順で全文字を一括描画するため、文字同士の境界が重ならず綺麗に仕上がります。

PNG と SVG 書き出しの使い分け
  • ロゴ透過PNG: そのままアイコン・動画テロップ・資料へ貼り付けられる高解像度ラスター画像。
  • ロゴ単体SVG: 拡大縮小しても劣化しないベクター形式。グラデーション・多重縁取り・ネオンフィルター・文字変形座標を保持して出力します。
  • 背景＋ロゴ合成PNG: Pattern工房で作成したシームレス背景とロゴを合成し、バナー（1200×630）やPC/モバイル壁紙解像度で書き出します。
