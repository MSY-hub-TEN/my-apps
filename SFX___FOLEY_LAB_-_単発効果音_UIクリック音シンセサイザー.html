Reference / Guide

Synthesizer Manual & Terminology

単発効果音（SE）・UIクリック音を作るための基本操作、シンセサイザー用語、およびWAV書き出し仕様のリファレンスです。

1. 基本操作とショートカット

トリガーパッドと連打テスト

大型の「TRIGGER SOUND」パッドをタップ、またはキーボードの Space キーを押すたびに発音します。ポリフォニック対応のため、UI操作音のように素早く連打しても音が途切れず自然に重なります。

Auto-Audition / Pitch Humanize

Auto-Audition をONにすると、スライダーを離した瞬間に自動で音が鳴ります。Pitch Humanize をONにすると発音ごとにピッチが微細に揺らぎ、連続タップ時の機械的な単調さを抑えます。

カテゴリ指定ランダム生成

UIクリック・チャイム・8bitレトロ・警告音・魔法/フォリーなどカテゴリを選んで RANDOMIZE を押すと、目的に合った破綻の少ない効果音を無限に探索できます。

完全ローカル処理

すべての音声合成・波形表示・WAVエンコードはブラウザ内蔵の Web Audio API と OfflineAudioContext のみで実行され、外部サーバーへの通信は一切発生しません。

2. オシレーター波形とノイズ成分

Sine（サイン波）

倍音を含まない最も純粋で丸い音。上品なUIタップ音、泡のポップ音、柔らかな通知ベルや決定チャイムの土台に最適です。

Triangle（三角波）

サイン波よりわずかに倍音があり、木琴やフルートのような温かみのある輪郭を持ちます。心地よい決定音やマイルドなレトロ音に向いています。

Square（矩形波）

中空でハッキリとしたデジタル質感の音。ファミコンやゲームボーイ風の8bitジャンプ音、コイン音、レトロな電子ブザーの主役になります。

Sawtooth（ノコギリ波）

最も倍音が豊かで鋭い音。警告アラーム、レーザーショット、フィルターと組み合わせた金属的なスイッチ音に効果的です。

White / Pink Noise

音程を持たない「シャー」というノイズ成分。Whiteは高域が鋭くカメラシャッターや硬い金属カチッ音に、Pinkは中低域が豊かで柔らかい打撃感や紙・空気の質感（Foley）に向いています。

3. シェイピング用語（Pitch / ADSR / Filter / Space）

Pitch Sweep（ピッチエンベロープ）

発音した瞬間から音程を急速に上下させる仕組みです。プラス方向（上昇）にすると「ジャンプ音・ポップ音・決定音」、マイナス方向（下降）にすると「レーザーショット・スイッチの沈み込み・キャンセル音」になります。

Secondary Tone / Chime Step（セカンドトーン）

主音から半音単位（Interval）で音程をずらした2つ目の音を重ねます。Step Delay を 0ms にすると和音（ベル・チャイム）、50〜100ms ずらすとコイン音や2音の成功ジングルが作れます。

ADSR + Hold（音量エンベロープ）

Attack：音の立ち上がり時間（クリック音は 1〜3ms）。 Decay：最大音量から減衰する時間。 Sustain Level / Hold：減衰後に音量を維持する高さと時間。 Release：音の消え際の余韻時間です。

Filter（LPF / HPF / BPF & Resonance）

LPF（ローパス）は高音を削って丸くし、HPF（ハイパス）は低音を削って軽くシャープにします。BPF（バンドパス）は特定の帯域だけを残すため、金属スイッチや電話音風の質感作りに便利です。Resonance (Q) を上げるとカットオフ付近が強調され、クセのある響きが生まれます。

Reverb / Delay と WAV書き出し

Reverbは空間の残響を、Delayはやまびこのような反復を加えます。書き出し形式は非圧縮の「16-bit PCM WAV」です。UI効果音やゲーム素材で容量を抑えたい場合は Mono、リバーブや空間的な広がりを活かしたいチャイム・魔法音は Stereo がおすすめです。

4. 実践レシピのヒント

  • 気持ちいいUIクリック音： Sine波（600〜1100Hz）、Pitch Sweep -10st前後（20ms）、Attack 1ms、Decay 30ms、Pink Noiseを10〜20%だけ短く（15ms）混ぜると、物理ボタンのような上質な手触りになります。
  • 硬質な金属スイッチ音： TriangleまたはSquare波を高め（1800Hz前後）にし、HPFまたはBPFで低域をカット。White Noiseを40%ほど加えてDecayを25ms程度に絞ります。
  • キラキラ・通知音： Sine波（1200Hz以上）＋ Secondary Tone（+7st または +12st、Step Delay 70ms）＋ Reverb Mix 40% ＋ Delay Mix 25% で澄んだ広がりが生まれます。
