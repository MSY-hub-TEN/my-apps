01 // CHROMA KEY & AUTO TRIM (前処理・透過)

イラストの単色背景を透明化し、ドット絵化の際に余白でキャラクターが小さくなるのを防ぎます。

  • PICK BG COLOR: ボタンを押してから中央モニターの元画像をクリックすると、その色が透過基準色に設定されます。
  • TOLERANCE (許容誤差): JPEGの圧縮ノイズやグラデーション背景をまとめて抜きたい場合は数値を上げます（推奨: 20〜45）。
  • AUTO TRIM MARGINS: 透明部分を自動検出し、被写体がキャンバスいっぱいに収まるよう余白を切り詰めます。

02 // RESOLUTION & PALETTE (解像度と減色)

用途に応じてレトロな低解像度から三桁の高精細ドットまで切り替え可能です。

  • 16〜64 PX: 動きが軽快なミニキャラ、ゲームアイコン、ダンスユニット向け。
  • 128〜256 PX: 髪型や衣装の細部を残す高精細ピクセルアート向け。
  • ORDERED DITHERING: 4x4ベイヤー行列を用いた網点処理です。色数を絞った際に滑らかな陰影の擬似グラデーションを作ります。
  • PIXEL OUTLINE: 透過境界の外側に1pxの縁取りを追加し、背景に埋もれないくっきりした輪郭を作ります。

03 // MOTION SYNTHESIZER & AUTO-SCALING

静止画1枚からピクセル単位の変形・上下バウンス・波打ち・パーティクル合成を行い、複数コマの差分を自動生成します。

  • 解像度自動スケーリング補正: 128pxや256pxなどの高解像度選択時、1px単位の移動では動きが小さくなりすぎるため、基準解像度（64px）に対する比率で移動幅を自動増幅します。
  • FRAME TIMELINE: 生成された各コマをクリックして選択し、個別にX/Y位置・縦伸縮（Squash）・パーティクルの種類を微調整できます。

04 // SPRITE SHEET & APP INTEGRATION

他の自作HTMLアプリやゲームエンジンですぐに使える形式で出力します。すべての処理はブラウザ内のみで完結し、外部サーバーへの画像送信は一切行われません。

  • SPRITE SHEET (.PNG): 全コマを横一列またはグリッド状に連結した透過PNGを書き出します。
  • BUILD JSON + DATA URL: コマ数・1コマあたりの幅/高さ・FPS・画像のBase64文字列をまとめたJSONを生成します。自作の「音乗りクルー」やランチャー等へそのままコピペして渡せます。
