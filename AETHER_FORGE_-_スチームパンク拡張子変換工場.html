01 // IMAGE BOILER

CANVAS 2D ENGINE
PNG (.png)
可逆圧縮（劣化なし）で透過（アルファチャンネル）に対応。ロゴ、UI素材、ドット絵、スクリーンショットの保存に最適です。
JPEG (.jpg)
写真向けに高い圧縮効率を持つ非可逆形式。透過は非対応のため、透過PNGをJPGへ変換する際は「背景色塗りつぶし」で白や任意の背景色を指定します。
WEBP (.webp)
透過対応かつJPG以上の高圧縮を実現する次世代Web標準形式。品質80〜85%設定で画質を維持しつつファイル容量を大幅に削減できます。
リサイズ & 拡大防止
幅または高さの一方のみを指定し「比率維持」を有効にすると、アスペクト比を保ったまま自動算出されます。「元サイズより拡大しない」を有効にすると小さな画像のボケを防ぎます。

02 // ACOUSTIC TURBINE

WEB AUDIO DSP
WAV (16-bit PCM) vs WebM / OGG (Opus)
WAVは非圧縮で劣化ゼロ・即座に書き出せるため、編集素材や効果音の保管に最適です。WebM/OGGはOpusコーデックによる軽量圧縮出力で、共有・持ち運びに適しています（※圧縮書き出しはブラウザのMediaRecorder仕様上、再生時間に応じた処理時間がかかります）。
サンプルレート (Hz) & モノラル化
44,100HzがCD標準、48,000Hzが映像・スタジオ標準です。声のメモや効果音ならモノラル(1ch)＋22,050Hzにすることで容量を約1/4へ削減できます。
前後無音トリミング (dBしきい値)
音声の先頭と末尾にある無音区間を自動除去します。-42dB前後が標準で、環境ノイズが大きい録音では-30dB付近へ上げると不要部分をカットしやすくなります。
音量ノーマライズ (Peak Normalize)
音声全体の最大ピークを指定したdB（標準 -1.0dB）まで均一に引き上げ、音割れ（クリッピング）を防ぎながら聞きやすい音量に揃えます。

03 // TEXT & DATA PRESS

PARSER & ENCODER
CSV ↔ JSON 相互変換
CSVの1行目をキー名としてJSONオブジェクト配列へ変換します。逆にJSON配列からは全キーを自動抽出して表形式のCSVやHTML/Markdownテーブルへ展開します。
Markdown ↔ HTML / TXT
Markdownから見出し・コードブロック・テーブル・引用を整えたスタンドアロンHTMLを生成します。逆にHTMLからタグを取り除きクリーンなTXTやMarkdownへ抽出することも可能です。
文字コード（UTF-8 / BOM / Shift-JIS読込）
読み込み時はUTF-8とShift-JISを自動判別して文字化けを防ぎます。出力時に「UTF-8 (BOM付)」を選ぶと、Windows版ExcelでCSVを開いた際の文字化けを防止できます。
改行コード (LF / CRLF)
LFはWeb開発・macOS・Linux標準、CRLFはWindowsメモ帳や一部業務ツール標準です。複数ファイルの混在を一括で統一できます。

04 // BATCH & COMFORT CONTROLS

WORKFLOW OPS
混在投入 & 一括ZIP梱包 (PACK ZIP)
画像・音声・テキストを同時にドロップしても自動で該当ボイラーへ振り分けられます。変換後は個別ダウンロードに加え、ワンクリックで全成果物を1つのZIPアーカイブにまとめて保存できます（オフライン時でも内蔵ZIP生成エンジンが自動動作します）。
MECHANICAL SFX / ANIMATION スイッチ
右上の独立トグルで、Web Audio APIによる機械スイッチ音・蒸気音（SFX）と歯車回転・蒸気演出（ANIM）をそれぞれ個別にON/OFFできます。静かな環境やバッテリー節約時も快適に使えます。設定はブラウザに自動記憶されます。
DIRECT TEXT INPUT & TEST SAMPLES
ファイル化されていないメモやJSONも「DIRECT TEXT INPUT」から直接貼り付けて変換・コピーできます。動作確認には「LOAD TEST SAMPLES」で画像・音声・データの3種サンプルを即座に生成できます。
